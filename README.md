## Project Overview

Customer Churn Prediction Using Machine Learning is a predictive analytics project designed to identify customers who are likely to discontinue using a company's services. The project applies multiple machine learning algorithms to analyze customer behavior and improve retention strategies.

## Machine Learning Models Used

- Logistic Regression
- Decision Tree
- Random Forest
- Gradient Boosting
- XGBoost

## Performance

- **Accuracy:** 92.6%
- **ROC-AUC Score:** 0.95

## Features

- Customer churn prediction
- Data preprocessing and feature engineering
- Comparative analysis of multiple ML models
- Model evaluation using Accuracy, Precision, Recall, F1-Score, and ROC-AUC
- Real-time prediction interface
- Data visualization and analytics dashboard

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- XGBoost
- Matplotlib
- Seaborn
- Jupyter Notebook

## Dataset

The project is trained and evaluated using telecom and banking customer datasets to predict customer churn with high accuracy.
